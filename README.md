# Vowel Counter

Simple Python program that counts vowels in a word.

## What it does
The user enters a word, and the program counts how many vowels (a, e, i, o, u) are in it.

## How it works
The program goes through each letter in the word and checks if it is a vowel. If yes, it increases the counter by 1.
